# Registo de episódios

- `registo.csv`: uma linha por episódio. Atualizar no fim de cada episódio (créditos = saldo inicial − saldo final do Higgsfield).
- `EPxxx/relatorio.md`: tema, fontes verificadas, créditos gastos (por geração), o que correu bem e mal.
- O código e os ficheiros de montagem de cada episódio ficam em `epxxx/` na raiz (como `ep001/`).
- Painel para o dono: ver o link no CLAUDE.md. Atualiza-se com os dados deste registo e do YouTube Analytics.
